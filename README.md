# Tertius Adjaoke — Portfolio

A single-page, static portfolio site built for GitHub Pages. No build step, no
framework; just HTML, CSS, and vanilla JavaScript.

## Folder structure

```
portfolio/
├── index.html

├── assets/
│   ├── images/
│   │   └── profile.jpg    
│   └── cv.pdf               
├── robots.txt
├── sitemap.xml
└── README.md
```
